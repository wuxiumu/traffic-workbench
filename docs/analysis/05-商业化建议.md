# 05 · 商业化建议（面向小白老板客群）

> 状态：建议稿 2026-11-13 ｜ 前提：v2 架构（Redis 热存 + SQLite 归档）已验证，单机 4c8g 可稳定服务数十站点

## 1. 产品定位

**给不懂技术的中小企业主/独立站长用的「开箱即用网站统计」**。对标产品：Umami/Plausible（自托管极简）、百度统计/友盟（免费但复杂）、Google Analytics（小白根本用不明白）。

差异化卖点（现有能力直接支撑）：
- 一行代码接入，复制粘贴即可（站点管理页已做到）
- 中文界面，只看三个数：多少人看（PV）、多少人来访（UV）、来自哪（IP/来源）
- 数据在自己服务器，隐私合规叙事好讲
- 实时访问动态 + 域名排名大屏（多站老板一眼看全局）

## 2. 三种商业形态（按投入排序）

| 形态 | 做法 | 定价参考 | 适配度 |
|---|---|---|---|
| A. 托管多租户 SaaS | 你运营一台/数台服务器，老板们注册即用（推荐首选） | ¥19–49/月/站点，年付折扣 | ★★★ 最贴合「小白」——什么都不用装 |
| B. 一键部署镜像/脚本 | 卖「私有化安装包」+ 收安装/年费服务费 | ¥299 一次性 + ¥99/年升级 | ★★ 适合有 IT 管理员的客户 |
| C. 开源核心 + 商业版 | GitHub 开源（当前仓库）引流，商业版加多用户/告警/导出 | 开源免费，Pro ¥x | ★★ 需持续社区运营 |

**建议路线：先 A 后 C**。A 用现有代码最小改造即可上线收费；跑通后把核心开源获客。

## 3. 形态 A（SaaS）所需改造清单（按优先级）

### P0 — 能收钱的最小闭环（1–2 周量级）
1. **多租户**：`users` 表 + 注册/登录（现有单管理员 auth 扩展为 user→sites 归属）；`sites` 加 `user_id`
2. **套餐与配额**：免费=1 站点/30 天数据；付费=N 站点/1 年数据（对应 `ARCHIVE_DAYS` 按租户配置）
3. **支付**：接虎皮椒/Stripe/微信支付宝当面码（个人可先用车库采集+人工开通降级起步）
4. **接入引导小白化**：注册后 3 步向导（填域名→复制代码→看到数据），配 1 分钟演示视频

### P1 — 留存与口碑
5. 邮件/微信通知：周报（本周 PV/UV 对比上周，直接发到老板微信）
6. 数据导出 Excel（老板爱拿去给员工看）— xlsx 表已有技能可复用
7. 多站点合并对比视图（现有 overview 排名表已是雏形）
8. 自定义告警：流量暴跌提醒（health-monitor 逻辑复用到业务指标）

### P2 — 规模化
9. 对象存储归档（SQLite → 按租户分库或迁 Postgres）、采集层水平扩展（Redis 限流已天然支持多实例）
10. 白标/代理分销：给建站公司/代理商，让他们贴牌卖给自己的客户

## 4. 运营与合规要点

- **备案**：SaaS 站点放国内必须 ICP 备案；采集脚本域名建议独立（stats.xxx.com）
- **隐私**：不采 Cookie、IP 仅哈希存储（已实现）→ 隐私政策好写；仍需在采集文档声明并给「关闭统计」说明
- **客服**：小白老板核心诉求是「有人管」——微信群里响应比功能更重要，定价里包含服务费
- **降本**：单台 4c8g 实测可承载几十站点/日百万级 PV（docs/analysis/04），前期一台够了；备份 cron + 监控 webhook 已内置

## 5. 定价锚点

| 档位 | 内容 | 价格 |
|---|---|---|
| 免费体验 | 1 站点 / 30 天历史 / 全功能 | ¥0 |
| 标准版 | 3 站点 / 1 年历史 / 周报 | ¥29/月 或 ¥299/年 |
| 专业版 | 10 站点 / 导出 / 告警 / 优先客服 | ¥99/月 或 ¥999/年 |

锚定：百度统计免费但小白不会配置；Plausible 云版 $9/月（≈¥65）——¥29 有显著价格优势，¥999/年对有多个站点的老板仍是小钱。

## 6. 本仓库与商业化的边界

- 本仓库保持「单管理员自托管版」定位（也就是形态 B 的产品本体），AGENTS.md 保证二次开发效率
- 形态 A 建议另起私有仓库 fork 演进（多租户改造涉及 auth/sites 大改，不要污染自托管主线的简洁性）
- 开源开源仓库时移除/替换演示数据与默认密码说明，保留 AGENTS.md（是社区贡献者的最好上手材料）
