## 2. 数据设计（独立命名空间 tw:u:*，与 keyed 站点完全隔离）

Redis：
- `tw:u:stats:{domain}:{date}` HASH {pv,uv,ip}
- `tw:u:vis:{domain}:{date}` / `tw:u:ips:{domain}:{date}` SET（UV/IP 日去重）
- `tw:u:events:{domain}:{date}` LIST（原始事件，供归档）
- `tw:u:site:{domain}` STRING 注册缓存（SETEX 300，避免热路径写 SQLite）

SQLite（新表）：
- `u_sites(domain PK, first_seen)` — 自动注册的域名
- `u_events(domain, ts, date, path, referrer, visitor_id, ip_hash)` — 归档明细
- `u_daily(domain, date, pv, uv, ip_count)` — 由 u_events 重算（REPLACE 幂等，同 keyed 口径）

归档：flush 扩展 SCAN `tw:u:events:*`（date<today）→ 批量入库 u_events → 重算 u_daily → DEL 键；u_events 同样按 ARCHIVE_DAYS 清理。
