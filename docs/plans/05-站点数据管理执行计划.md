## 2. 导出格式（v1）

```json
{
  "version": 1,
  "exportedAt": 1699…,
  "sites":   [{ "key","name","domain","createdAt" }],
  "events":  [{ "key","ts","date","path","referrer","visitorId","ipHash" }]
}
```

- events = SQLite 归档段（date < windowStart）∪ Redis 窗口段（`tw:events:{key}:{date}` LRANGE）——完整无缺
- 聚合表不导出：导入侧由 events **重算**（recomputeDay），口径天然一致；若 JSON 无 events（手工构造）则直接 REPLACE 写聚合（兼容）

## 3. 导入语义（幂等合并）

- 站点：按 site_key upsert（存在→更新名称/域名；不存在→创建，保留原 key）
- 事件：删除该站点 [minDate, maxDate] 范围内 events 后整段插入（**按日期段替换**，重复导入不产生重复行）
- 聚合：对出现过的每个 date 执行 recomputeDay
- 同时清掉该站 Redis 窗口键（避免导入历史后 Redis 窗口残留旧数据双算——窗口日若在导入范围内）
