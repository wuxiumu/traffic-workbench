## 3. 上线步骤（4 核 8GiB 服务器）

```bash
# 1) 服务器装 Docker + compose 插件，上传项目
# 2) 配置 .env（ADMIN_PASSWORD / IP_SALT / CRON_SECRET 必改）
# 3) 起服务
docker compose up -d --build
docker compose ps            # app + redis 均 healthy
# 4) Nginx 反代 127.0.0.1:3000（X-Forwarded-For 必传）+ certbot HTTPS
# 5) 网站接入：站点管理 → 复制 m.js 嵌码
# 6) 监控：health-monitor.mjs crontab（WEBHOOK_URL 通知）
# 7) 备份：traffic.db 每日快照 + redis-data 卷随 docker volume 备份
```
