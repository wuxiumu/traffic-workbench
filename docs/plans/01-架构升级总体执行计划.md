## 3. 关键约束（实施时必须遵守）

1. 热路径禁写 SQLite（站点缓存未命中的读除外）
2. 每个日期只从单一来源读：`date >= windowStart` → Redis，否则 SQLite
3. 归档幂等：聚合一律 REPLACE...SELECT 重算，禁止增量累加落库
4. 今日 events 键永不归档（并发写保护）
5. 所有新参数进环境变量并同步 README 表格
